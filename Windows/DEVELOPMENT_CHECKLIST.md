# Windows 端开发清单

> Windows 端开发遵守仓库根目录 `AGENTS.md` 的通用开始、结束、Git 协作和硬件安全规则。
> 本文件只记录 Windows 任务、验收条件和进度，不重复通用约束。

## 当前边界

- 正式 Windows 实现是 `Windows/DisplaySwitcher.Native/`，技术栈为原生 C++/WinUI 3。
- `Windows/DisplaySwitcher.Launcher/` 是绿色版入口启动器，正式构建仍需要它。
- `Windows/DisplaySwitcher.Windows/` 是旧 C# 迁移参照，不参与正式构建；不要在其中实现新功能。
- `PROTOCOL.md` 是 Mac/Windows 通信的唯一规范；当前正式运行时为 v2-only。未经双端同步设计，不得单方面改变消息结构或行为。
- macOS 与 Windows 均已完成动态多显示器模型；Windows 端当前仅剩设置页和高 DPI 交互的实机验证待确认。
- 不要重写现有托盘、WinUI 3、USB 监控、UDP、DDC 或登录启动实现，只做可验证的渐进式迁移。
