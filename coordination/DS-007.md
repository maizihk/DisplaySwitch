## 已发现差异

1. Windows 有关于弹窗代码但没有独立关于标签。
2. macOS 设置页没有完整的三项 DDC 滑杆和每项托盘显示开关。
3. macOS 联动开关位于常规页，Windows 位于显示器页。
4. 两端仍使用全局取消/保存，且协同检测确认文案依赖再次保存。
5. macOS 标题和浅色内容背景不符合用户要求。
6. Windows 托盘没有 DDC 调节入口及对应显示开关。
7. 当前 `PROTOCOL.md`、两端运行时和公共回归仍要求 v1 兼容，与用户的新决定冲突。
8. macOS 初始状态仍由 v1 选择逻辑生成，可能长期显示旧配置名、“等待心跳”或不准确的“无响应”。
9. macOS DDC 滑杆没有按显示器/VCP 合并连续写入，原生传输句柄失败后也没有明确的失效重建压力验收。
10. Windows 当前 DDC 开关重复显示标签、开关状态和 VCP 编号，并让简单开关占用过多垂直空间；两端需要统一紧凑的一项一行布局。
11. 两端五个设置页的信息层级、用词、字段顺序、密度和状态反馈尚未形成同一套产品规范。
