# DS-004 跨平台功能对齐

- 功能编号和名称：DS-004 跨平台功能对齐
- 任务类型：cross-platform
- 当前状态：READY_FOR_PLATFORM（本机模型/UI 第一阶段已合并；显示控制、Windows USB 学习和关于页面待实施）
- 当前基线：`016ae59f502af6c6f3fe1f312888dbba41b0fd45`

## 目标和边界

核对 macOS 与 Windows 当前真实实现，区分必须完全一致的公共行为、语义应一致但实现可不同的能力、合理的平台差异以及需要用户决定的产品范围。

本审计不要求两端复制相同 UI，不修改平台代码、handoff、开发清单、`PROTOCOL.md`、contracts、GitHub Actions、Release、tag 或版本号，也不执行真实 USB、DDC、显示器唤醒或防火墙操作。

## 兼容、迁移和降级策略

- 两端本机配置已经迁移至 `schemaVersion = 3`；该版本仅用于本机数据，不进入网络消息。
- macOS 读取现有 v2、`Displays.Configuration.v1` 数组和旧双显示器键；失败时保留原数据并持久停用自动硬件动作，只有用户成功保存才能解除。
- 未知配置版本必须安全拒绝，不能猜测字段语义或覆盖用户配置。
- 平台专有后端不可用时应报告可用性并安全降级，不得误操作其他显示器。
- Windows v3 已建立全局显示器目录和旧对端协同配置；v2 `MacInput` 原值迁入该配置的 `peerInput`，全局 `localInput = null`。
- macOS v3 已将 v2 `macInput` 迁为全局 `localInput`，将 `windowsInput` 迁入旧对端配置的 `peerInput`。
- 任一平台 v3 写入失败时必须保留原 v2 数据并进入持久安全状态；名称和角色字段只保存在本机。
