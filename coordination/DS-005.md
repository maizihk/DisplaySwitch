# DS-005 多目标协同协议 v2

- 功能编号和名称：DS-005 多目标协同协议 v2
- 任务类型：cross-platform
- 当前状态：READY_FOR_PLATFORM
- 平台实施基线：以本次协议协调 PR 合并后的 `main` 为准
- 前置功能基线：`7bac3aeb714c9e38f754951a3cc45091bdfc9e90`（DS-004 完成）
- 网络协议：`version = 2`，与 v1 独立并存
- 本机数据：复用 DS-004 `schemaVersion = 3`，不新增公共配置同步
- proposal：`specs/proposals/DS-005-multi-target-coordination-protocol-v2.md`
- contracts：`contracts/protocol-v2/`

## 公共用户行为

1. 手动选择配置时，目标明确：先请求该 endpoint 唤醒和确认，再执行该配置的显示器映射。
2. 自动切换且只有一个已开启配置时，直接与唯一目标协同。
3. 自动切换且有多个已开启配置时，等待对端发送通过认证的 `input_present`；首个合法声明立即且不可变地锁定目标。
4. 多目标发现窗口为 3 秒，不设置 250 ms 仲裁窗口。
5. 3 秒内没有合法目标时不猜测配置、保持零 DDC，并提示用户手动选择。
6. 配置检测只进行版本、endpoint 和认证能力确认，不触发 USB、蓝牙、唤醒或 DDC。

## 协议与公共数据状态

- `PROTOCOL.md` 已在协调分支 `codex/coord-ds-005-protocol-effective` 纳入完整 v2 规范，同时原样保留 v1 兼容语义。
- v2 使用随机逻辑 endpointID，不依赖 `macos` / `windows` 平台枚举判断身份。
- v2 使用 PBKDF2-HMAC-SHA256：200000 次、32 字节发送方向密钥；配对码不得进入网络消息。
- v2 认证覆盖所有已知业务字段、endpoint、时间戳和 nonce；接收端使用常量时间比较。
- nonce 为 16 个安全随机字节，接收端重放缓存至少 20 秒；相同 nonce 对不同认证字段安全拒绝。
- v1 与 v2 按 `version` 进入独立解析器和状态机；不得把 v2 手动、蓝牙或多目标行为编码为 v1 消息。

## 公共测试向量

- v2：4 个 schema、1 条 NFC 规范化向量、4 条认证向量、20 条消息验证向量和 P-001 至 P-020 共 20 条状态机向量。
- v1 回归：3 个 schema、17 条消息向量和 16 条状态机向量。
- 两个平台必须把两套向量接入各自原生测试目标；协调脚本不能代替平台测试。
- 所有自动测试必须使用模拟时钟、网络、输入设备、唤醒和 DDC。

## Windows 任务范围

- 实现 v2 消息模型、严格解析、PBKDF2/HMAC、规范化认证输入、常量时间校验、nonce 重放缓存和 v1/v2 分派。
- 按 `localEndpointID`、配置 `peerEndpointID` 和已确认协议能力路由，不依赖平台名称选择目标。
- 实现手动定向、单配置自动、多配置 3 秒发现三条状态机路径。
- 将现有 USB 监测和后续蓝牙到达适配为不含设备标识的逻辑 `input_present`。
- 保留现有 v1 状态机、DDC、配置迁移、安全门及全部回归测试。
- 分支、提交、PR、构建、测试和 CI：待 Windows Agent 实施并更新 `handoffs/windows.md`。

## macOS 任务范围

## 兼容、迁移和安全降级

- DS-004 `schemaVersion = 3` 已具备本机和对端 endpoint/协议能力字段，不升级本机 schema。
- 首次合法 v2 检测得到 endpointID 后必须等待用户确认；已保存 endpointID 变化时不得自动替换。
- `仅 v1` 的单配置只允许现有 Mac/Windows USB 交接；不能参与手动 v2 唤醒、蓝牙声明、同系统协同或多目标发现。
- 多配置、认证失败、未知版本、错误 endpoint、发现超时或配置变化时保持当前显示器状态，不猜测目标。
- 关闭或回退 v2 不得删除本机 schema v3 配置，也不得影响本机显示器控制。

## 未解决差异

平台运行时尚未实现 v2。Windows 和 macOS 必须从同一协议合并基线分别实现，且不得修改共享协议、contracts 或另一平台目录。

## 已批准决定

1. 使用 HMAC-SHA256，配对码不直接进入 v2 消息。
2. 多目标发现窗口为 3 秒。
3. 不设置仲裁窗口，首个通过认证的合法声明立即锁定目标。
4. 发现超时保持零 DDC并转手动选择。
5. 用户已授权继续未完成功能并减少非必要流程；本次以一个协调 PR 完成 DS-004 记录收尾和 v2 协议生效，不运行无关平台构建。
