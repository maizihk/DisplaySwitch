## 公共行为定义

DS-005 为 DS-004 的多个协同配置提供网络行为，分为：

1. 用户手动选择配置：目标明确，先请求目标唤醒和确认，再执行该配置的显示器输入映射。
2. 自动切换且只有一个已开启配置：直接与唯一目标协同。
3. 自动切换且有多个已开启配置：等待各对端根据本机 USB/蓝牙设备到达发送逻辑声明，首个通过认证的合法声明立即锁定目标。

目标锁定后其他声明不得覆盖或产生硬件副作用；3 秒超时仍无目标时不得猜测配置，不执行 DDC，提示用户手动选择。

## 兼容、迁移和降级

- v1 与 v2 按 `version` 进入独立解析器和状态机，不改变已发布 v1 字段语义。
- v1-only 配置只允许现有单目标 Mac/Windows USB 交接，不参与多目标发现、蓝牙声明、手动协同唤醒或同系统协同。
- 无合法目标、认证失败、未知版本或协商失败时保持当前显示器状态并提示用户。
- DS-005 不同步 DS-004 本机显示器、触发设备或 profile 硬件数据。

## 未解决差异

- 当前 v1 只使用平台角色，无法区分同平台多个 endpoint。
- 当前 v1 `usb_present` 不能表达蓝牙或通用输入设备到达。
- 当前手动入口没有独立的网络协同意图。
- v2 已确认并写明 HMAC-SHA256、PBKDF2、规范化输入、nonce 和重放规则；公共 contracts 已获用户批准并通过协调侧验证，仍待双端原生测试。

## 已批准决定

1. v2 采用 HMAC-SHA256，配对码不直接进入网络消息。
2. 多目标发现总窗口为 3 秒。
3. 不设置仲裁窗口；首个通过认证的合法声明立即锁定目标。
4. 3 秒超时无目标时保持零 DDC 并要求手动选择。
