# DS-008 本机 USB 双向切换

- 功能编号和名称：DS-008 本机 USB 双向切换
- 任务类型：cross-platform
- 当前状态：PROTOCOL_REVIEW
- 当前基线：`main@c6452412b9fb6543501a83181103eadc6e6d9666`
- 公共行为：USB 离开立即执行本机 DDC；USB 接入只唤醒本机显示器；全程不依赖网络协同
- 协议 version：当前生效仍为 `version = 2`；待用户明确批准删除 USB 网络协同语义
- 数据 schemaVersion：提议从 4 升到 5，保留非 USB v4 数据并重建关闭的独立 USB 配置
- proposal：`specs/proposals/DS-008-local-usb-switch.md`
- contracts：待批准后更新 `contracts/protocol-v2/`

## 公共行为定义

1. 两端 USB 功能只监听用户明确选择的一个本机 USB 设备。
2. 初始状态只建立基线，零硬件和网络副作用。
3. `接入 → 离开` 不等待网络、心跳、确认或应用层防抖，立即异步执行本机显示器输入源切换。
4. `离开 → 接入` 只请求一次本机显示器唤醒，不执行 DDC。
5. 重复状态通知幂等；学习、安全状态、配置重载和关闭期间零副作用。
6. USB 配置独立保存设备和每显示器目标输入源，不读取协同配置。

## 公共测试向量

提案定义 USB-001 至 USB-012。它们只使用逻辑 presence、模拟 DDC、模拟唤醒和网络零调用计数，不记录真实 USB 或显示器标识。

## 已发现差异

- 当前两端均把 USB presence 送入 v2 协同状态机。
- 当前 macOS 只有 v2 路由存在且 USB 引用集合恰好为一个时才真正监听设备。
- 当前 Windows 使用顶层 USB VID/PID，但切换目标仍来自协同 profile。
- 当前协议仍定义单目标和多目标 USB 网络协同，与 DS-008 已确认方向冲突。
