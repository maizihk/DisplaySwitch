## 公共行为定义

1. 两端 USB 功能只监听用户明确选择的一个本机 USB 设备。
2. 初始状态只建立基线，零硬件和网络副作用。
3. `接入 → 离开` 不等待网络、心跳、确认或应用层防抖，立即异步执行本机显示器输入源切换。
4. `离开 → 接入` 只请求一次本机显示器唤醒，不执行 DDC。
5. 重复状态通知幂等；学习、安全状态、配置重载和关闭期间零副作用。
6. USB 配置独立保存设备和每显示器目标输入源；联动关闭时不读取协同配置。
7. 联动开启时只并行发送一次认证 `wake_display`；发送失败不影响 DDC，目标端与本机 USB 接入唤醒在 2 秒内合并为一次。

## 公共测试向量

`contracts/usb-switch-v1/` 定义 USB-001 至 USB-016。它们只使用逻辑 presence、模拟 DDC、模拟唤醒和模拟网络，不记录真实 USB 或显示器标识。

## 已解决差异

- 两端 USB presence 已从 v2 协同状态机移除，改为独立本机协调器。
- macOS USB 监听已与 v2 路由解耦；Windows 显示器目标已改为独立 USB 映射。
- 公共协议已删除旧 USB 网络交接，联动只允许认证 `wake_display`。
- macOS 主动 UDP 已从临时源端口改为复用本机 `listenPort`；目标端口仍使用配置的 `peerPort`，与 Windows 首次来源校验一致。
